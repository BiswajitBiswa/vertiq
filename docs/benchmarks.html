Benchmarks

Planted truths, five seeds each

Every scenario is synthetic with a known answer, so each result can be checked against it. Means ± standard deviation over 5 seeds; the whole suite runs in 28 seconds on arm64 with Python 3.10.10.

What a plugin adds

What these don't show. Synthetic benchmarks prove the machinery: it finds a real signal, ignores noise and refuses to ship a worse model. They do not prove accuracy on your data; the evaluation gate measures that on your own held-out records every time it trains. Public datasets (Online Retail II, the Hillstrom email uplift test, NASA C-MAPSS engines) are next.

Run them

python benchmarks/run.py --seeds 5        # writes benchmarks/results/core.json
python benchmarks/collect_lm.py --lm lm   # summarises scored Vertiq LM runs into results/lm.json
python docs/build.py                      # rebuilds this portal from both
