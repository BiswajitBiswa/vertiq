Architecture

One contract, general tasks, one gate

Vertiq never reads a database or calls a network. A host maps its records once, calls functions, and stores the models (plain dicts) wherever it likes. That boundary is a test: tests/test_boundary.py fails if the package imports a web framework, an ORM or an HTTP client.

Extend without forking

Register features and rules under a pack name and pass pack= to a task. A feature sees only events before the cutoff, so it can't leak the future. Any class with fit, predict, to_dict and from_dict can be a learner.

Run anywhere

No dependencies at all, Python 3.10+. Training on a few hundred thousand rows takes seconds on a laptop; scoring at a till is a few dictionary lookups.

Embed it in any product

A host keeps only glue on its side: reading its database into the contract and serving results. Nothing in this package knows which product embeds it.
