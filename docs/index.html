Local decision models

Decision models for any business, trained on its own outcomes

Vertiq predicts what happens next to a customer, a machine, a patient or an account. It measures what actually worked against a control group, and it only ships a model that beats the obvious rule on records it never saw. Pure Python, no dependencies; it runs on a laptop, a server or a till.

Three ideas

Map once

Any sector's records become entities, events and actions. Vertiq LM proposes the mapping from a header and three rows; the rows correct it.

Ask general questions

Will it happen within N days? How much will the next one be worth? Who does a message bring back? The same tasks answer them in every sector.

Earn its place

Every model is tested on entities it never saw, against the obvious rule and the model you already run. If it doesn't win, you keep what you had.

Quick start

pip install git+https://github.com/BiswajitBiswa/vertiq

from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event

m, notes = repair(Mapping.parse({"entity": "Equipment No", "time": "Work Order Date", "type": "Order Type",
                                 "value": "Cost", "group": "Plant", "attrs": [], "date_format": "%Y-%m-%d"}), rows)
ds, problems = apply(m, rows)
task = predict_event(ds, target="breakdown", window_days=30)
print(task.status, task.report()["metrics"])   # trained, kept (baseline wins) or learning (too little data)
print(task.score("EQ-602"))                    # {"chance": 0.31, "raises": [...], "lowers": [...]}
