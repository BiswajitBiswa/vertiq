Telecom and utilities

Predict churn and unusual usage per subscriber or meter, and size the next bill.

mapping tested not yet tested

Your records in Vertiq's terms

entity
subscriber or meter
group
circle or zone
profile
generic (set your own windows with verticals.register)

Questions you can ask

  • Will this subscriber recharge within 30 days? predict_event(target="recharge", window_days=30)
    Usage Type holds data, voice, sms and recharge rows.
  • What will the next month's usage be? predict_value(target="data", window_days=30)

Working example

from datetime import datetime, timedelta
from vertiq import plugins, rules
from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event, predict_value

# rows: your export as a list of dicts, e.g. list(csv.DictReader(open("export.csv")))
mapping = Mapping.parse({"entity": "Abonne", "time": "Date Usage", "type": "Usage Type", "value": "Conso", "group": "Circle", "attrs": ["Plan"], "date_format": "%Y-%m-%d"})
m, notes = repair(mapping, rows)      # the rows settle column names, value types and the date format
ds, problems = apply(m, rows)         # any row that didn't load is named, never guessed

@plugins.feature("telco")
def usage_trend(entity, before, cut):   # only events before the cutoff: no peeking
    m1 = sum(e.value for e in before if e.at >= cut - timedelta(days=30))
    m2 = sum(e.value for e in before if cut - timedelta(days=60) <= e.at < cut - timedelta(days=30))
    return {"usage_ratio": (m1 + 1) / (m2 + 1)}

task = predict_event(ds, target="recharge", window_days=30, pack="telco")
print(task.status, task.report())     # "trained" only if it beat the baseline on held-out entities
if task.status == "trained":
    print(task.score("9812345670"))  # the chance, and what raises or lowers it

size = predict_value(ds, target="data", window_days=30, pack="telco")
print(size.status, size.report())

flags = rules.run(ds, [
    rules.repeat(1, type="complaint"),   # two complaints in a day
])
print(flags["summary"])

This exact code runs in the test suite (tests/test_guides.py) against generated rows in these column names.

Domain knowledge: usage_trend

Usage falling month on month comes before most churn.
