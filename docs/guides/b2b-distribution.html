B2B distribution and invoicing

See which accounts are ordering less, which invoices will be paid late, and what each account buys next.

Questions you can ask

  • Will this account place an order within 90 days? predict_event(target="INV", window_days=90)
  • How large will its next invoice be? predict_value(target="INV", window_days=90)

Working example

from datetime import datetime, timedelta
from vertiq import plugins, rules
from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event, predict_value

# rows: your export as a list of dicts, e.g. list(csv.DictReader(open("export.csv")))
mapping = Mapping.parse({"entity": "Cuenta", "time": "Fecha Factura", "type": "Tipo Doc", "value": "Net Value", "group": "Sales Org", "attrs": ["Payment Terms", "Sales Rep", "Due Date", "Paid Date"], "date_format": "%d.%m.%Y"})
m, notes = repair(mapping, rows)      # the rows settle column names, value types and the date format
ds, problems = apply(m, rows)         # any row that didn't load is named, never guessed

@plugins.feature("b2b")
def credit_notes_180(entity, before, cut):   # only events before the cutoff: no peeking
    return {"crn_180": sum(1 for e in before if e.type == "CRN"
                          and e.at >= cut - timedelta(days=180))}

task = predict_event(ds, target="INV", window_days=90, pack="b2b")
print(task.status, task.report())     # "trained" only if it beat the baseline on held-out entities
if task.status == "trained":
    print(task.score("ACC4399"))  # the chance, and what raises or lowers it

size = predict_value(ds, target="INV", window_days=90, pack="b2b")
print(size.status, size.report())

flags = rules.run(ds, [
    rules.overdue("Due Date", "Paid Date", tolerance_days=15),   # invoices paid more than 15 days after they were due
])
print(flags["summary"])

This exact code runs in the test suite (tests/test_guides.py) against generated rows in these column names.

Domain knowledge: credit_notes_180

Credit notes (CRN) often come before an account cools; count them.

Checks

  • rules.overdue("Due Date", "Paid Date", tolerance_days=15): invoices paid more than 15 days after they were due

Also useful

  • affinity: SKUs ordered together; each account's next SKU
  • value.campaign_value: extra revenue a campaign earned against its control accounts

Before you rely on it

  • Map credit notes as their own type so they are not counted as orders.
