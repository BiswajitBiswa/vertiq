Vertiq LM

An open 4B model that maps any table, trained on a Mac

Vertiq LM's first job is the step every sector needs: reading an unfamiliar export and saying which column is the entity, the time, the event type, the value and the group. It is Qwen 3.5 4B (Apache-2.0), fine-tuned with LoRA on an M1 Pro with 16 GB, scored on tables from domains it never saw.

What worked

Showing the model what each column holds (read from the values by code) lifted never-seen domains from 14.6% to 31.2% exactly right. Letting the rows decide the date format and the value types lifted every model.

What didn't, yet

DPO ran out of memory on 16 GB because it keeps a reference copy; ORPO replaced it. The round-3 ORPO step also ran out of memory with other apps open and is waiting for a free machine. Constrained decoding was measured and dropped: it would fix 2 of 88 remaining errors.

Reproduce

lm/make_data.py → lm/train.sh → lm/evaluate.py → lm/collect_failures.py → lm/pref.sh; lm/round3.sh runs the realistic round end to end.
