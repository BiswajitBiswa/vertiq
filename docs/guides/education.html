Education

See which students are disengaging from attendance and assessments, early enough to help.

mapping tested not yet tested

Your records in Vertiq's terms

entity
student (pseudonymous id)
group
school or section
profile
generic (set your own windows with verticals.register)

Questions you can ask

  • Will this student attend within the next 7 days? predict_event(target="attendance", window_days=7)
    Activity holds attendance, assessment and assignment rows.
  • What score is likely on the next assessment? predict_value(target="assessment", window_days=60)

Working example

from datetime import datetime, timedelta
from vertiq import plugins, rules
from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event, predict_value

# rows: your export as a list of dicts, e.g. list(csv.DictReader(open("export.csv")))
mapping = Mapping.parse({"entity": "Chhatra ID", "time": "Date", "type": "Activity", "value": "Score", "group": "School", "attrs": ["Subject", "Section", "Due", "Submitted"], "date_format": "%d-%m-%Y"})
m, notes = repair(mapping, rows)      # the rows settle column names, value types and the date format
ds, problems = apply(m, rows)         # any row that didn't load is named, never guessed

@plugins.feature("school")
def absence_streak(entity, before, cut):   # only events before the cutoff: no peeking
    days = sorted({e.at.date() for e in before if e.type == "attendance"})
    gap = (cut.date() - days[-1]).days if days else 999
    return {"days_since_present": gap}

task = predict_event(ds, target="attendance", window_days=7, pack="school")
print(task.status, task.report())     # "trained" only if it beat the baseline on held-out entities
if task.status == "trained":
    print(task.score("S4402"))  # the chance, and what raises or lowers it

size = predict_value(ds, target="assessment", window_days=60, pack="school")
print(size.status, size.report())

flags = rules.run(ds, [
    rules.overdue("Due", "Submitted", tolerance_days=2, type="assignment"),   # assignments more than two days late
])
print(flags["summary"])

This exact code runs in the test suite (tests/test_guides.py) against generated rows in these column names.

Domain knowledge: absence_streak

A run of absences matters more than the total.

Checks

  • rules.overdue("Due", "Submitted", tolerance_days=2, type="assignment"): assignments more than two days late

Before you rely on it

  • Use scores to offer help, never to label or rank students publicly.
  • Keep student data pseudonymous and follow your school's data policy.
