Sector guides / Healthcare and clinics

Healthcare and clinics

Flag likely readmissions and missed follow-ups, and estimate the length of the next stay.

benchmarked mapping tested

Your records in Vertiq's terms

entity
patient (pseudonymous id)
group
hospital or clinic
profile
generic (set your own windows with verticals.register)

Questions you can ask

  • Will this patient be readmitted within 30 days? predict_event(target="admission", window_days=30)
  • How long will the next stay be? predict_value(target="admission", window_days=120)

Working example

from datetime import datetime, timedelta
from vertiq import plugins, rules
from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event, predict_value

# rows: your export as a list of dicts, e.g. list(csv.DictReader(open("export.csv")))
mapping = Mapping.parse({"entity": "Patienten Nr", "time": "Admit Date", "type": "Encounter Type", "value": "LOS Days", "group": "Klinik", "attrs": ["Diagnosis Code", "Ward", "Follow-up Due", "Follow-up Done"], "date_format": "%d/%m/%Y"})
m, notes = repair(mapping, rows)      # the rows settle column names, value types and the date format
ds, problems = apply(m, rows)         # any row that didn't load is named, never guessed

@plugins.feature("clinic")
def chronic_codes(entity, before, cut):   # only events before the cutoff: no peeking
    chronic = {"E11", "I50", "J44"}
    return {"chronic": float(any(e.attrs.get("Diagnosis Code") in chronic for e in before))}

task = predict_event(ds, target="admission", window_days=30, pack="clinic")
print(task.status, task.report())     # "trained" only if it beat the baseline on held-out entities
if task.status == "trained":
    print(task.score("P29999"))  # the chance, and what raises or lowers it

size = predict_value(ds, target="admission", window_days=120, pack="clinic")
print(size.status, size.report())

flags = rules.run(ds, [
    rules.repeat(30, type="admission"),   # readmission within 30 days
    rules.overdue("Follow-up Due", "Follow-up Done", tolerance_days=3),   # follow-ups more than 3 days late
])
print(flags["summary"])

This exact code runs in the test suite (tests/test_guides.py) against generated rows in these column names.

Domain knowledge: chronic_codes

A clinician's list of chronic diagnosis codes is domain knowledge the data won't state.

Checks

  • rules.repeat(30, type="admission"): readmission within 30 days
  • rules.overdue("Follow-up Due", "Follow-up Done", tolerance_days=3): follow-ups more than 3 days late

Before you rely on it

  • Decision support only: scores rank who to review first and never replace a clinician.
  • Use pseudonymous ids; keep names and contact details out of the data you map.
  • Follow local health-data law (for example DPDP in India, HIPAA in the US) and your ethics process.

Evidence so far

  • benchmarked Length of stay: error 1.61 days against 2.18 for the same-as-last-time baseline (5 seeds)
  • mapping tested Healthcare tables in the Vertiq LM mapping test
