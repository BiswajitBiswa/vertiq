Finance and portfolio operations

Find dormant clients and accounts that need a call, from their own activity. Not trading signals.

Questions you can ask

  • Will this client buy within 60 days? predict_event(target="BUY", window_days=60)

Working example

from datetime import datetime, timedelta
from vertiq import plugins, rules
from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event, predict_value

# rows: your export as a list of dicts, e.g. list(csv.DictReader(open("export.csv")))
mapping = Mapping.parse({"entity": "Depot", "time": "Fecha Operacion", "type": "Tipo", "value": "Monto", "group": "Estrategia", "attrs": ["Moneda", "Broker"], "date_format": "%d.%m.%Y"})
m, notes = repair(mapping, rows)      # the rows settle column names, value types and the date format
ds, problems = apply(m, rows)         # any row that didn't load is named, never guessed

@plugins.feature("wealth")
def withdrawals_90(entity, before, cut):   # only events before the cutoff: no peeking
    return {"sells_90": sum(1 for e in before if e.type == "SELL"
                           and e.at >= cut - timedelta(days=90))}

task = predict_event(ds, target="BUY", window_days=60, pack="wealth")
print(task.status, task.report())     # "trained" only if it beat the baseline on held-out entities
if task.status == "trained":
    print(task.score("DP-2041"))  # the chance, and what raises or lowers it

flags = rules.run(ds, [
    rules.repeat(1, type="SELL"),   # two sells on the same account in a day, for review
])
print(flags["summary"])

This exact code runs in the test suite (tests/test_guides.py) against generated rows in these column names.

Domain knowledge: withdrawals_90

A run of withdrawals often comes before a client leaves.

Checks

  • rules.repeat(1, type="SELL"): two sells on the same account in a day, for review

Before you rely on it

  • Vertiq predicts client behaviour, not prices. It gives no investment advice.
  • Keep regulated decisions with licensed people; use scores to decide who to call.
