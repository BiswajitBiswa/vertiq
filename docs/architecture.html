Architecture

Architecture

Vertiq is a library, not a service. The host application loads its records into a common data contract, calls Vertiq functions and stores the resulting models, which are plain dictionaries. The package does not import web frameworks, ORMs or HTTP clients; tests/test_boundary.py enforces this.

Modules

taskspredict_event and predict_value for any event type, with contributing factors for each score

churn · uplift · valueCustomer retention, intervention uplift, transaction value and campaign revenue

inventoryReorder points, slow-moving stock, new items and margins
learnRegularised logistic and linear models, AUC, Brier score, calibration and Benjamini–Hochberg
verticalsIndustry profiles: time windows, terminology and currency
dataset · research · trendsTraining data export for language models, cited external tactics and trend matching

Extensibility

Features and rules are registered under a pack name and selected with pack=. Custom learners require fit, predict, to_dict and from_dict; per-group offsets and contributing factors are optional.

Deployment footprint

Python 3.10 or later with no third-party dependencies. The complete benchmark suite runs in 28 seconds on a laptop.

Integration

The host application owns data access, storage and serving. The library has no knowledge of the product that embeds it.
