Logistics and delivery

Predict which shipments run late and which customers ship less, from scan and delivery events.

mapping tested not yet tested

Your records in Vertiq's terms

entity
customer or route

generic (set your own windows with verticals.register)

Questions you can ask

  • Will this shipper book within 7 days? predict_event(target="picked", window_days=7)
  • How heavy will their next consignment be? predict_value(target="picked", window_days=30)

Working example

from datetime import datetime, timedelta
from vertiq import plugins, rules
from vertiq.mapping import Mapping, apply, repair
from vertiq.tasks import predict_event, predict_value

# rows: your export as a list of dicts, e.g. list(csv.DictReader(open("export.csv")))
mapping = Mapping.parse({"entity": "Shipper ID", "time": "Scan Time", "type": "Status", "value": "Weight Kg", "group": "Hub", "attrs": ["Service Level"], "date_format": "%Y-%m-%d %H:%M"})
m, notes = repair(mapping, rows)      # the rows settle column names, value types and the date format
ds, problems = apply(m, rows)         # any row that didn't load is named, never guessed

@plugins.feature("logistics")
def late_share(entity, before, cut):   # only events before the cutoff: no peeking
    done = [e for e in before if e.type == "delivered"]
    late = [e for e in done if e.attrs.get("Service Level") == "late"]
    return {"late_share": len(late) / max(1, len(done))}

task = predict_event(ds, target="picked", window_days=7, pack="logistics")
print(task.status, task.report())     # "trained" only if it beat the baseline on held-out entities
if task.status == "trained":
    print(task.score("SHP-2210"))  # the chance, and what raises or lowers it

size = predict_value(ds, target="picked", window_days=30, pack="logistics")
print(size.status, size.report())

flags = rules.run(ds, [
    rules.repeat(3, type="exception"),   # a second delivery exception within three days
])
print(flags["summary"])

This exact code runs in the test suite (tests/test_guides.py) against generated rows in these column names.

Domain knowledge: late_share

Customers who had late deliveries ship less; count them.

Checks

  • rules.repeat(3, type="exception"): a second delivery exception within three days

Before you rely on it

  • Map one event per scan only if you need it; daily counts are often enough.
